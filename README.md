# Simulador de Abastecimiento de Carburantes - Trabajo Final

## Autor
- **Estudiante:** Andres Fabian Guzman Quisbert[cite: 1]
- **Materia:** Programación Web I[cite: 1]

## Descripción del Proyecto
Este proyecto es una aplicación educativa interactiva diseñada en cumplimiento del Desafío Final de Programación Web I[cite: 1]. Simula matemáticamente el comportamiento del inventario de combustible en una estación de servicio frente a la crisis actual de abastecimiento[cite: 1]. Permite proyectar de forma dinámica el total de días útiles de reserva basándose en entradas de consumo, reservas críticas y cargas periódicas de combustible[cite: 1].

## Tecnologías Utilizadas
- **HTML5:** Estructuración semántica de la interfaz[cite: 1].
- **CSS3:** Estilos adaptativos (Responsive Design), paleta de colores de alta legibilidad y componentes interactivos[cite: 1].
- **JavaScript (Vanilla):** Manejo de la lógica del simulador, validaciones aritméticas de datos y manipulación dinámica del DOM[cite: 1].

## Estructura del Repositorio
El proyecto se encuentra organizado bajo la arquitectura de directorio indicada:
